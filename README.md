# Heart Haven: Children's Home Support Platform

A learning prototype built with HTML, CSS and JavaScript only. All names, figures and stories are fictional sample data, and payments are simulated.

## Status
- **Stage 1 (planning):** done
- **Stage 2 (static pages):** done. 8 responsive pages and a shared stylesheet
- Stage 3+ (dynamic content, forms, admin): to do

## Pages
`index.html`, `programmes.html`, `needs.html`, `support.html`, `volunteer.html`, `impact.html`, `contact.html`, `admin.html`

## Structure
```
css/style.css     shared styles (design tokens at the top)
js/main.js        mobile menu toggle
images/           placeholder SVG illustrations (replace with real images later)
```

## Running it
Open `index.html` in a browser, or use the VS Code "Live Server" extension. Fonts and icons load from Google Fonts, so an internet connection is needed.
